# فهرس الآيات والأحاديث والآثار – المباحث 6–9 من الفصل الأول (ch1b)

## أولًا: الآيات القرآنية

| طرف الآية | السورة: الرقم |
|---|---|
| ﴿وَاتَّخِذُوا مِنْ مَقَامِ إِبْرَاهِيمَ مُصَلًّى﴾ | البقرة: 125 |
| ﴿وَلَا تُبَاشِرُوهُنَّ وَأَنْتُمْ عَاكِفُونَ فِي الْمَسَاجِدِ﴾ | البقرة: 187 |
| ﴿وَأَحَلَّ اللَّهُ الْبَيْعَ وَحَرَّمَ الرِّبَا﴾ | البقرة: 275 |
| ﴿يَا أَيُّهَا الَّذِينَ آمَنُوا اتَّقُوا اللَّهَ وَذَرُوا مَا بَقِيَ مِنَ الرِّبَا...﴾ | البقرة: 278–279 |
| ﴿لَا يُكَلِّفُ اللَّهُ نَفْسًا إِلَّا وُسْعَهَا﴾ | البقرة: 286 |
| ﴿وَمَا كَانَ لِنَبِيٍّ أَنْ يَغُلَّ وَمَنْ يَغْلُلْ يَأْتِ بِمَا غَلَّ يَوْمَ الْقِيَامَةِ﴾ | آل عمران: 161 |
| ﴿يَا أَيُّهَا الَّذِينَ آمَنُوا لَا تَأْكُلُوا أَمْوَالَكُمْ بَيْنَكُمْ بِالْبَاطِلِ...﴾ | النساء: 29 |
| ﴿لَا تَقْرَبُوا الصَّلَاةَ وَأَنْتُمْ سُكَارَى... وَلَا جُنُبًا إِلَّا عَابِرِي سَبِيلٍ﴾ | النساء: 43 |
| ﴿إِنَّ اللَّهَ يَأْمُرُكُمْ أَنْ تُؤَدُّوا الْأَمَانَاتِ إِلَى أَهْلِهَا﴾ | النساء: 58 |
| ﴿وَأَخْذِهِمُ الرِّبَا وَقَدْ نُهُوا عَنْهُ﴾ | النساء: 161 |
| ﴿يَا أَيُّهَا الَّذِينَ آمَنُوا أَوْفُوا بِالْعُقُودِ﴾ | المائدة: 1 |
| ﴿وَتَعَاوَنُوا عَلَى الْبِرِّ وَالتَّقْوَى وَلَا تَعَاوَنُوا عَلَى الْإِثْمِ وَالْعُدْوَانِ﴾ | المائدة: 2 |
| ﴿لَا تَخُونُوا اللَّهَ وَالرَّسُولَ وَتَخُونُوا أَمَانَاتِكُمْ﴾ | الأنفال: 27 |
| ﴿وَأَوْفُوا بِالْعَهْدِ إِنَّ الْعَهْدَ كَانَ مَسْئُولًا﴾ | الإسراء: 34 |
| ﴿وَمَا جَعَلَ عَلَيْكُمْ فِي الدِّينِ مِنْ حَرَجٍ﴾ | الحج: 78 |
| ﴿إِنَّ خَيْرَ مَنِ اسْتَأْجَرْتَ الْقَوِيُّ الْأَمِينُ﴾ | القصص: 26 |
| ﴿فَاتَّقُوا اللَّهَ مَا اسْتَطَعْتُمْ﴾ | التغابن: 16 |
| ﴿وَأَنَّ الْمَسَاجِدَ لِلَّهِ فَلَا تَدْعُوا مَعَ اللَّهِ أَحَدًا﴾ | الجن: 18 |
| ﴿وَيْلٌ لِلْمُطَفِّفِينَ * الَّذِينَ إِذَا اكْتَالُوا عَلَى النَّاسِ يَسْتَوْفُونَ...﴾ | المطففين: 1–3 |

| مرّ النبي ﷺ بتمرة في الطريق فقال: «لولا أني أخاف أن تكون من الصدقة لأكلتها» | أنس بن مالك | البخاري (2431) |
| «المسلمون على شروطهم إلا شرطًا حرم حلالًا أو أحل حرامًا» | عمرو بن عوف المزني / أبو هريرة | الترمذي (1352)، أبو داود (3594) |
| «من استعملناه على عمل فرزقناه رزقًا فما أخذ بعد ذلك فهو غلول» | بريدة | أبو داود (2943) |
| «من استعملناه منكم على عمل فكتمنا مخيطًا فما فوقه كان غلولًا» | عدي بن عميرة الكندي | مسلم (1833) |
