# فهرس الآيات والأحاديث والآثار في الفصل الرابع (ch4)

## أولًا: الآيات القرآنية

| طرف الآية | السورة: الرقم |
|---|---|
| ﴿قُلْ مَنْ حَرَّمَ زِينَةَ اللَّهِ الَّتِي أَخْرَجَ لِعِبَادِهِ﴾ | الأعراف: 32 |
| ﴿أَطِيعُوا اللَّهَ وَأَطِيعُوا الرَّسُولَ وَأُولِي الْأَمْرِ مِنْكُمْ﴾ | النساء: 59 |
| ﴿لَا يُكَلِّفُ اللَّهُ نَفْسًا إِلَّا وُسْعَهَا﴾ | البقرة: 286 |
| ﴿وَلَا يُبْدِينَ زِينَتَهُنَّ إِلَّا مَا ظَهَرَ مِنْهَا وَلْيَضْرِبْنَ بِخُمُرِهِنَّ عَلَى جُيُوبِهِنَّ﴾ | النور: 31 |
| ﴿يُدْنِينَ عَلَيْهِنَّ مِنْ جَلَابِيبِهِنَّ﴾ | الأحزاب: 59 |
| ﴿وَلَا تَبَرَّجْنَ تَبَرُّجَ الْجَاهِلِيَّةِ الْأُولَى﴾ | الأحزاب: 33 |
| ﴿ذَلِكَ أَدْنَى أَنْ يُعْرَفْنَ فَلَا يُؤْذَيْنَ﴾ | الأحزاب: 59 |
| ﴿وَمَا كَانَ لِمُؤْمِنٍ وَلَا مُؤْمِنَةٍ إِذَا قَضَى اللَّهُ وَرَسُولُهُ أَمْرًا﴾ | الأحزاب: 36 |
| ﴿لَا إِكْرَاهَ فِي الدِّينِ﴾ | البقرة: 256 |
| ﴿إِلَّا أَنْ تَكُونَ تِجَارَةً عَنْ تَرَاضٍ مِنْكُمْ﴾ | النساء: 29 |
| ﴿يَا أَيُّهَا الَّذِينَ آمَنُوا أَوْفُوا بِالْعُقُودِ﴾ | المائدة: 1 |
| ﴿وَإِنْ كَانَ ذُو عُسْرَةٍ فَنَظِرَةٌ إِلَى مَيْسَرَةٍ﴾ | البقرة: 280 |
| ﴿وَلَا تَكْتُمُوا الشَّهَادَةَ وَمَنْ يَكْتُمْهَا فَإِنَّهُ آثِمٌ قَلْبُهُ﴾ | البقرة: 283 |
| ﴿وَلَا تَزِرُ وَازِرَةٌ وِزْرَ أُخْرَى﴾ | الأنعام: 164 |
| ﴿وَمَا جَعَلَ عَلَيْكُمْ فِي الدِّينِ مِنْ حَرَجٍ﴾ | الحج: 78 |

## ثانيًا: الأحاديث النبوية

| طرف الحديث | الراوي |
|---|---|

| «من أحدث في أمرنا هذا ما ليس منه فهو رد» | عائشة |
| «من تشبّه بقوم فهو منهم» | ابن عمر |
| «إن هذه من ثياب الكفار فلا تلبسها» | عبد الله بن عمرو بن العاص |
| «لعن رسول الله ﷺ المتشبهين من الرجال بالنساء...» | ابن عباس |
| «قضى أن لا ضرر ولا ضرار» | عبادة بن الصامت |
| «لتلبسها أختها من جلبابها» | أم عطية |
| «لا تقبل صلاة الحائض إلا بخمار» | عائشة |
| «يا أسماء إن المرأة إذا بلغت المحيض لم يصلح لها أن يرى منها إلا هذا وهذا» | عائشة (مرسل) |
| «من لبس ثوب شهرة ألبسه الله يوم القيامة ثوبًا مثله» | ابن عمر |
| «مروا أولادكم بالصلاة وهم أبناء سبع سنين...» | عبد الله بن عمرو (عمرو بن شعيب عن أبيه عن جده) |
| «من رأى منكم منكرًا فليغيره بيده...» | أبو سعيد الخدري |
| «احتجبا منه» (في ابن أم مكتوم) | أم سلمة (نقله النبهاني) |
| «كان الركبان يمرون بنا ونحن مع رسول الله ﷺ محرمات...» | عائشة (نقله النبهاني) |
| «لا تنتقب المرأة المحرمة ولا تلبس القفازين» | ابن عمر (نقله النبهاني) |
| «رأيت شابًّا وشابة فلم آمن الشيطان عليهما» | علي بن أبي طالب (نقله النبهاني) |
| «من جر ثوبه خيلاء لم ينظر الله إليه... يرخين شبرًا» | ابن عمر وأم سلمة (نقله النبهاني) |
| «إنما البيع عن تراض» | أبو سعيد الخدري |
| «من احتكر فهو خاطئ» / «لا يحتكر إلا خاطئ» | معمر بن عبد الله |
| «إن الله هو المسعّر القابض الباسط الرازق...» | أنس بن مالك |
| «بل الله يخفض ويرفع» | أبو هريرة |
| «إن أحق ما أخذتم عليه أجرًا كتاب الله» | ابن عباس |
| «مطل الغني ظلم» | أبو هريرة |
| «ليّ الواجد يحلّ عرضه وعقوبته» | الشريد بن سويد |
| «لا يبع حاضر لباد، دعوا الناس يرزق الله بعضهم من بعض» | جابر بن عبد الله |
| «إن كنت تحب أن تطوق طوقا من نار فاقبلها» (قوس عبادة) | عبادة بن الصامت |
| شهود النساء العيد و«يهوين بأيديهن يقذفنه في ثوب بلال» | ابن عباس (احتج به ابن حزم) |
| قصة الخثعمية وتحويل النبي ﷺ وجه الفضل | ابن عباس (احتج به ابن حزم) |
